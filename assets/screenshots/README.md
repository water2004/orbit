# UI screenshots

These are captures of the actual Orbit Vue/Tauri frontend rendered with the
isolated `orbit-gui/ui/tests/workflows.html` fixture. Instance names, accounts and
runtime data are demonstrations, not a user's files or a running Minecraft game.
No screenshot is a design mockup. The GUI is GPL-3.0-only; its upstream artwork
and attribution are documented in `orbit-gui/ui/UPSTREAM.md`.
