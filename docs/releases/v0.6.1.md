# Orbit 0.6.1

Orbit 0.6.1 improves dependency-conflict diagnostics so an unsatisfiable package set names the actual opposing constraints.

## Highlights

- When no version set can satisfy the declared packages, `fix`, `install`, and the other solving commands now report both sides of the real conflict — for example, one package requiring `fabric-api >= 0.159.0` while another pins `fabric-api = 0.158.0+26.2` — instead of blaming only the side that happened to fail first. The PubGrub fork performs one final preference-free solve in this cold path, so the returned derivation tree contains only genuine dependency facts and never mistakes a keep-current preference for the cause.
- Conflict facts no longer list the same declared version once per candidate source; identical version segments are shown only once.

## Packages

- Windows: `orbit-0.6.1-x86_64.msi` provides the selectable Orbit, Orbit + Launcher, and full Orbit + Launcher + GUI installation profiles.
- Linux: `orbit_0.6.1-1_amd64.deb`, `orbit-launcher_0.6.1-1_amd64.deb`, and `orbit-gui_0.6.1-1_amd64.deb` remain independently installable.

# Orbit 0.6.1（简体中文）

Orbit 0.6.1 改进了依赖冲突诊断：包集合无解时，报错会指出真实的对立约束双方。

## 重点改进

- 当没有任何版本组合能满足声明的包集合时，`fix`、`install` 等求解命令现在会同时报告冲突双方——例如一个包要求 `fabric-api >= 0.159.0`，而另一个包钉死 `fabric-api = 0.158.0+26.2`——而不是只显示碰巧先失败的一侧。PubGrub fork 在这条冷路径上会额外做一次不带偏好强制的求解，返回的推导树只包含真实依赖事实，不会把"保持当前版本"的偏好误判为冲突原因。
- 冲突事实不再把同一声明版本按候选来源重复列出，相同版本段只显示一次。

## 安装包

- Windows：`orbit-0.6.1-x86_64.msi` 继续提供仅 Orbit、Orbit + Launcher、Orbit + Launcher + GUI 三种安装组合。
- Linux：`orbit_0.6.1-1_amd64.deb`、`orbit-launcher_0.6.1-1_amd64.deb`、`orbit-gui_0.6.1-1_amd64.deb` 可独立安装。
