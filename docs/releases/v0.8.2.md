# Orbit 0.8.2

- Choose official downloads or BMCLAPI to improve connectivity, including public version metadata and game resources.
- View crash reports directly in the GUI. Closing the launcher no longer stops a running game; automatic closing is optional.
- Set each instance's initial and maximum memory with sliders or precise values. Existing settings upgrade automatically with backups.
- Fixed server startup staying stuck in the activity panel after the server had started.
- Fixed Forge installer spec 0 being incorrectly rejected during installation and import. Unsupported audit versions no longer block launching or mod management.
- Uninstall with a choice of keeping your settings, removing settings but keeping instances, or removing everything. Program removal clears caches in every mode.

Windows: one unsigned MSI (requires WebView2). Linux: separate Orbit, Launcher and GUI DEBs.

## 简体中文

- 支持选择官方源或 BMCLAPI，改善公开版本信息和游戏资源的下载体验。
- 可直接在 GUI 查看崩溃报告；关闭启动器不再结束游戏，也可设置启动后自动关闭。
- 支持用滑块或精确数值设置每个实例的初始、最大内存；旧配置自动升级并备份。
- 修复服务端已经启动、活动面板却始终显示正在启动的问题。
- 修复安装、导入时错误拒绝 Forge spec 0 安装器的问题；不支持审计的版本不再因此阻止启动和模组管理。
- 卸载提供保留设置、删除设置但保留实例、全部删除三档选择；所有模式均清理程序缓存。

Windows 提供一个未签名 MSI（需要 WebView2）；Linux 分别提供 Orbit、Launcher、GUI 三个 DEB。
