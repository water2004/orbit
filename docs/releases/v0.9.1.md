# Orbit 0.9.1

- Added Settings → About, with version information and manual GitHub Release update checks.
- Fixed the instance selector shrinking into an unreadable narrow menu. Long instance names now wrap in the list.
- Fixed missing padding and text alignment in Launcher settings cards.

Existing instances and configuration remain unchanged. Update checks open the release page; they do not install updates automatically.

Windows: one unsigned MSI (requires WebView2). Linux: separate Orbit, Launcher and GUI DEBs.

## 简体中文

- 新增“设置 → 关于”，可查看版本并手动检查 GitHub 正式版更新。
- 修复实例选择器缩成窄条的问题，列表中的长实例名称支持换行。
- 修复 Launcher 设置卡片缺少内边距、文字贴边的问题。

现有实例和配置保持不变。检查更新后可打开发布页面，不会自动安装。

Windows 提供一个未签名 MSI（需要 WebView2）；Linux 分别提供 Orbit、Launcher、GUI 三个 DEB。
