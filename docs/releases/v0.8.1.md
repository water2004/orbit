# Orbit 0.8.1

- Improved Microsoft login reliability by retrying temporary Xbox Live, XSTS and Minecraft Services failures.
- Choose Modrinth and CurseForge search sources per instance from Discover, or through `orbit config --scope instance`.
- Vanilla instances launch without Orbit; new modded instances automatically initialize their mod workspace.
- Existing instances, settings and accounts remain compatible with 0.8.0; no format migration is required.

## 简体中文

- 改善正版登录的可靠性，自动重试 Xbox Live、XSTS 和 Minecraft Services 的暂时性网络故障。
- 可在“发现模组”或 `orbit config --scope instance` 中为每个实例设置 Modrinth、CurseForge 搜索来源。
- 原版实例无需 Orbit 即可启动；新建模组实例时自动初始化模组工作区。
- 兼容 0.8.0 的实例、设置和账户，无需迁移数据格式。
