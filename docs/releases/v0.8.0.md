# Orbit 0.8.0

- Import existing client instances from HMCL, PCL and other supported launchers without changing the originals. Added complete instance deletion with confirmation and system trash support.
- Improved instance-bound mod discovery, dialogs, installation controls, settings, icons and progress feedback.
- Prefer compatible local Java, with global and per-instance selection. Existing v0.7.0 Launcher settings and instances upgrade automatically with backups.
- Single-mod upgrades prioritize the selected mod while minimizing changes to the rest.
- Fixed migration choices, version filtering, world-data restoration and synchronization of upgraded instances.
- Automatically retry transient network failures and interrupted downloads.

Windows: one unsigned MSI (requires WebView2). Linux: separate Orbit, Launcher and GUI DEBs.

## 简体中文

- 支持从 HMCL、PCL 等已适配启动器导入客户端实例，不改变原实例；新增完整删除实例，操作前确认并使用系统回收站。
- 改进绑定实例的模组发现、弹窗、安装控件、设置、图标与进度反馈。
- 优先使用兼容的本地 Java，支持全局与单实例选择；自动升级 v0.7.0 的 Launcher 设置和实例格式，并保留备份。
- 单模组升级优先更新指定模组，尽量减少其他模组的变动。
- 修复迁移方案选择、版本过滤、世界数据恢复，以及实例升级后的模组同步问题。
- 自动重试瞬时网络故障和下载中断。

Windows 提供一个未签名 MSI（需要 WebView2）；Linux 分别提供 Orbit、Launcher、GUI 三个 DEB。
