# Orbit 0.2.0

Orbit 0.2.0 首次把模组包管理器、Minecraft 运行时 Launcher 与原生桌面薄壳作为同版本套件
发布。Orbit 本体的目标没有变化：模组与依赖图仍只由 `orbit` 管理；Launcher 不调用 Orbit，
GUI 也不链接任何 core，三者只在用户工作流与机器协议边界组合。

## Orbit

- 明确分离命令职责：`sync` 联网恢复来源并重建本地事实但不求解，`fix` 才求解和修复，
  `install` 只精确物化已有 lock。
- 一个逻辑包可以同时拥有本地文件、Modrinth 与 CurseForge 远端；候选按内容哈希去重，包
  身份、版本与依赖只信任下载后的 JAR。
- 求解器枚举标准 Pareto 极大解并保留真实推导原因；所有会改变包集合的方案在应用前明确
  展示升级、降级、安装与删除差异。
- 加入基于真实目标运行时的 `migrate check/export`、可复用 Orbit 源包和 Modrinth mrpack
  导入导出，以及可取消的字节级进度。
- Fabric、Quilt、Forge、NeoForge 使用各自 Loader 规则完成多逻辑模组、嵌套内容、运行时
  namespace、Mixin 激活与字节码 audit，再进入共享领域模型。

## Orbit Launcher

- 从官方 Minecraft 与 Loader metadata 一条命令创建 Vanilla、Fabric、Quilt、Forge、
  NeoForge 的隔离客户端或明确目录的独立服务端。
- 管理 Mojang Java runtime、版本/Loader 更新、客户端启动，以及带 IPC、取消和崩溃重启的
  服务端 supervisor；服务端安装和运行坚持完整展示并明确接受 Minecraft EULA。
- 支持 Microsoft、Offline 与标准 External Yggdrasil 账户、Authlib Injector 和失效后的
  明确重新登录流程；皮肤纹理由 Launcher 规范化为本地头像供 GUI 展示。
- 内置 Orbit 自有的 Microsoft public-client ID
  `a1b083c0-2c7f-47c8-a351-451279131fc7`。Client ID 不是秘密；refresh/access token 仍只进入
  Windows DPAPI 或 Linux Secret Service。

## 原生 GUI

- 使用 GPUI/gpui-component 构建，不包含 WebView；它是两套 CLI JSON/NDJSON/stdin 协议的
  薄壳，覆盖实例安装与迁移、Java、账户、服务端、模组搜索/方案选择/更新、audit 与配置。
- 提供中英文与系统语言、主题/强调色、任务进度和可取消 Activity、连续触控板滚动、远端及
  JAR 模组图标、Minecraft 皮肤头像和统一应用品牌资源。
- 升级迁移先导出并校验源包，再创建目标实例，最后复用同一迁移规划器导出目标 Orbit 状态
  并调用 `install` 物化，不在 GUI 内复制业务逻辑。

## 安装包与升级说明

- **Windows x64**：`orbit-0.2.0-x86_64.msi`，安装向导可选 Orbit、Orbit + Launcher 或完整
  三件套；支持 PATH、同版本维护和卸载时可选清理默认 AppData。
- **Debian/Ubuntu amd64**：`orbit_0.2.0-1_amd64.deb`、
  `orbit-launcher_0.2.0-1_amd64.deb`、`orbit-gui_0.2.0-1_amd64.deb`。无图形服务器应只安装
  Launcher，需要模组管理时再加 Orbit；GUI 精确依赖同版本两个 CLI。
- **完整性校验**：下载 `SHA256SUMS` 后执行 `sha256sum --check SHA256SUMS`。

0.2.0 是 pre-1.0 的接口整理版本：旧的 Launcher 独立 `launcher-v*` 发布、独立 MSI、Linux
聚合 deb、可配置 Microsoft client ID 和旧机器协议兼容路径均已移除。升级前请备份实例和
全局配置；严格 schema 不匹配时应按当前文档重建对应状态，程序不会静默猜测或迁移旧格式。

Windows MSI 当前未使用项目代码签名证书；请在安装前核对 Release 页面中的 SHA-256。
