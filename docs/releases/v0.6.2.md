# Orbit 0.6.2

- Faster update checks and upgrade planning for large mod collections, with lower memory use, especially when many independent version choices exist.
- Clearer solver progress in both the CLI and GUI, distinguishing the search for better solutions from checks that choices can be combined independently.

Existing configurations and instances need no migration.

Downloads: one Windows MSI for Orbit, Launcher and GUI; three separate Linux DEB packages.
