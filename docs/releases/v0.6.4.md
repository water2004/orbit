# Orbit 0.6.4

- Fixes GUI crashes when choosing files for modpack imports and exports, and applies the same fix to other file and folder pickers.
- Fixes adding Modrinth projects by slug, such as `fabric-api`, including on fresh installations.
- Shows project IDs in CLI search results so they can be copied directly into `orbit add`.
- Supports Fabric Loader 0.20.x for runtime file ownership tracking and bytecode audits.

Existing configurations and instances need no migration.

Downloads: one Windows MSI for Orbit, Launcher and GUI; three separate Linux DEB packages. The Windows MSI is unsigned.

## 简体中文

- 修复 GUI 在导入、导出整合包时选择文件导致崩溃的问题，并统一修复其它文件和目录选择入口。
- 修复使用 `fabric-api` 等 Modrinth slug 添加模组失败的问题，包括全新安装后的情况。
- CLI 搜索结果现在显示项目 ID，可直接复制用于 `orbit add`。
- 支持 Fabric Loader 0.20.x 的运行时文件归属追踪和字节码审计。

现有配置和实例无需迁移。

下载：Windows 使用包含 Orbit、Launcher 和 GUI 的一个 MSI；Linux 提供三个独立 DEB 包。Windows MSI 尚未签名。
