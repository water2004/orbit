# Orbit 0.7.0

- Redesigned desktop app with a clearer instance library, guided installation, and dedicated mod and account management.
- Improved update and migration reviews: choose each option first, then confirm the complete plan.
- More usable progress, cancellation, scrolling, and light/dark themes.

Windows: one MSI (requires WebView2). Linux: separate Orbit, Launcher, and GUI DEBs.

## 简体中文

- 全新桌面界面：更清晰的实例库、分步安装向导，以及独立的模组和账户管理。
- 改进更新与迁移确认：逐步选择方案，最后核对并应用完整更改。
- 改进进度提示、取消操作、滚动体验和深浅主题。

Windows 提供一个 MSI（需要 WebView2）；Linux 分别提供 Orbit、Launcher 和 GUI 的 DEB。
