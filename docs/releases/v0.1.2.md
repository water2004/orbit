# Orbit 0.1.2

Orbit 0.1.2 修复 0.1.1 中 Fabric dedicated server 的 Mojang bundler 内层游戏 JAR
路径解析错误。建议所有 0.1.1 用户直接升级。

## 修复

- `META-INF/versions.list` 的第三列按 Mojang bundler 的实际定义解释为相对
  `versions/` 的完整路径，例如 `26.1.2/server-26.1.2.jar`。
- 不再把版本 ID 重复拼入路径，因此不会错误访问
  `versions/26.1.2/26.1.2/server-26.1.2.jar`。
- 回归测试使用官方落盘形态，并继续验证内层游戏 JAR 与 bundler library 的清单 hash。

该修复不增加文件名猜测或兼容兜底。Fabric、Quilt、Forge、NeoForge 仍使用 0.1.1
引入的同一严格服务器运行时模型；`init` 和 `sync` 只接受安装器元数据所指向且通过校验的
实际 JAR。

## 安装包

- **Windows x64**：`orbit-0.1.2-x86_64.msi`
- **Debian/Ubuntu amd64**：`orbit_0.1.2-1_amd64.deb`
- **完整性校验**：下载 `SHA256SUMS` 后执行
  `sha256sum --check SHA256SUMS`

0.1.2 不修改 `orbit.toml` / `orbit.lock` schema。未成功完成 `orbit init` 的服务器可在
升级后直接重新运行；已存在项目无需迁移。
