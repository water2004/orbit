# Orbit 0.2.1

Orbit 0.2.1 是 0.2 系列的状态一致性与桌面登录修复版本，三个程序继续使用同一个套件版本。

## 修复与改进

- `sync` 现在让 TOML、lock 和分组精确收敛到磁盘包集合，删除已经没有本地 JAR 的包状态；
  遇到同一包的多个物理实现时清空无法如实表达的旧 lock 选择，并要求由 `fix` 明确求解。
- 新增 `orbit enable/disable <package>`，以 `.jar` / `.jar.disabled` 原子切换 Loader 激活状态，
  同时维护 TOML 和精确 lock；init、sync、install、迁移与归档都理解该状态。
- `orbit add` 不再暗中插入版本字符串规则。GUI 默认勾选的 `beta` / `snapshot` 排除策略会把
  完整规则显式传入 `--string`，用户取消勾选后不传约束。
- GUI 的 Microsoft 设备授权会自动打开系统浏览器，并始终显示明确可点击的 HTTPS 登录页、
  验证码、复制按钮和 Microsoft 返回的说明。
- Launcher 的共享可变 Minecraft asset index 使用按内容寻址的实例物化，避免不同实例覆盖
  同一路径时发生安装冲突。
- 本地候选版本库按精确 Minecraft/Loader 作用域缓存 Provider 快照与 JAR 分析结果，降低重复
  请求、下载和解析。

## Windows 安装包

`orbit-0.2.1-x86_64.msi` 继续提供 Orbit、Orbit + Launcher、完整套件三个安装选项，并支持
同版本维护、可选 PATH 与卸载时选择是否清理默认 AppData。
