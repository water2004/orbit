# Orbit 0.9.0

- Instance actions now have explicit targets. Instance cards show the account used to launch; third-party accounts display their endpoint names.
- Fixed CurseForge searches failing on some projects. Search sources save automatically when changed.
- Fixed version rules passing build suffixes as numeric bounds; exact builds remain selectable separately.
- Fixed server dependency handling: required client-only libraries can be installed without being treated as loaded server mods. Missing or manually disabled dependencies still fail validation.
- CLI package management is now grouped under `orbit package <mod_id>`. Instance and account commands have also been reorganized; update existing scripts using the [command reference](https://github.com/water2004/orbit/blob/v0.9.0/docs/orbit-cli-commands.md).

Existing instance configuration and lockfiles keep their formats. Windows: one unsigned MSI (requires WebView2). Linux: separate Orbit, Launcher and GUI DEBs.

## 简体中文

- 实例操作目标更加明确；实例卡片显示启动账户，第三方账户显示端点名称。
- 修复部分 CurseForge 项目搜索失败；修改搜索来源后自动保存。
- 修复版本后缀被误传为数字边界的问题，仍可单独锁定完整构建版本。
- 修复服务端依赖处理：可以安装必需的客户端库，但不会将其视为已加载的服务端模组；缺失或手动禁用依赖仍会报错。
- CLI 包管理统一到 `orbit package <mod_id>`，实例与账户命令也已整理；旧脚本需要按[命令文档](https://github.com/water2004/orbit/blob/v0.9.0/docs/orbit-cli-commands.md)更新。

现有实例配置和 lock 文件格式保持不变。Windows 提供一个未签名 MSI（需要 WebView2）；Linux 分别提供 Orbit、Launcher、GUI 三个 DEB。
