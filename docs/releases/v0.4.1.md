# Orbit 0.4.1

Orbit 0.4.1 is a focused compatibility and packaging maintenance release.

## Highlights

- The Runtime Agent relocates its bundled ASM classes so Fabric and other loaders can safely provide their own ASM version on the game classpath.
- The bytecode audit now reports conditional `@Overwrite` target failures from plugin-controlled Mixins instead of suppressing the structural risk entirely. This catches incompatible Iris/Sodium combinations before launch without claiming that every plugin-controlled Mixin always applies.
- Windows MSI and the suite package metadata are aligned at version 0.4.1.

## Packages

- Windows: `orbit-0.4.1-x86_64.msi` installs Orbit and its Runtime Agent, Orbit Launcher, and Orbit GUI using the selected setup profile.
- Linux: `orbit_0.4.1-1_amd64.deb`, `orbit-launcher_0.4.1-1_amd64.deb`, and `orbit-gui_0.4.1-1_amd64.deb` remain independently installable.

The Windows MSI is currently unsigned, so Windows may display an unknown-publisher warning.

## 简体中文

Orbit 0.4.1 是一次聚焦兼容性与打包流程的维护版本。

- Runtime Agent 将内置 ASM 类重定位，避免 Fabric 等 Loader 在游戏类路径提供自己的 ASM 版本时发生重复类冲突。
- 字节码 audit 现在会报告插件控制 Mixin 中条件性的 `@Overwrite` 目标缺失，而不再完全隐藏结构风险；它可以在启动前发现 Iris/Sodium 这类不兼容组合，同时不会错误声称插件 Mixin 一定执行。
- Windows MSI 与套件包元数据统一为 0.4.1。

Windows MSI 目前没有代码签名，系统可能显示“未知发布者”提示。
