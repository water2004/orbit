# Orbit 0.1.0

Orbit 0.1.0 是首个公开预览版本。它把已有 Minecraft 实例作为真实来源：读取游戏、
Loader 与 Mod JAR，建立可复现的 manifest/lock，再由同一套下载、元数据、求解和事务
路径完成安装、同步、升级与审计。

## 安装包

- **Windows x64**：`orbit-0.1.0-x86_64.msi`
- **Debian/Ubuntu amd64**：`orbit_0.1.0-1_amd64.deb`
- **完整性校验**：下载 `SHA256SUMS` 后执行
  `sha256sum --check SHA256SUMS`

Windows MSI 提供安装目录、系统 PATH、维护/修复和卸载数据保留选项。当前 MSI 尚未使用
项目代码签名证书；Windows 可能显示未知发布者提示。

Debian 包把 `orbit` 安装到 `/usr/bin/orbit`。卸载 MSI 或 deb 默认都不会删除
Minecraft 实例；deb 也不会删除用户 XDG 配置与缓存。

## 核心能力

### 真实 JAR 身份与多来源

- 包身份、版本、依赖、端侧和嵌套关系只信任下载后 JAR 内的 Loader 元数据。
- Modrinth、CurseForge 与本地 `file:` 是同等的候选远端；跨 provider 的相同内容按
  SHA-512 合并，同版本不同内容仍作为不同候选交给求解器。
- 递归发现远端 project 依赖，先形成完整候选下载队列，再统一下载、缓存、解析，求解器
  阶段保持离线。
- CurseForge 使用独立 HTTP wrapper 与 core adapter，且必须显式配置用户自己的 API
  Key；不存在匿名或共享 Key 降级路径。

### Loader 统一元数据模型

- Fabric、Quilt、Forge 与 NeoForge 进入同一个规范化元数据、候选图、lockfile 和事务
  流程。
- 支持一个物理 JAR 声明多个逻辑 Mod、Fabric/Quilt nested JAR、Forge-family JarJar、
  `provides`、端侧、加载顺序与软/硬依赖。
- Fabric/Quilt 使用 Fabric predicate；Forge/NeoForge 使用 Maven
  ComparableVersion/range。
- Loader-owned JSON 兼容字符串内未转义的控制字符，与 Fabric Loader 的读取行为对齐；
  注释、尾逗号、单引号等其它非标准语法仍然报错。

### 可解释依赖求解

- Orbit 使用定制 PubGrub fork，让依赖原因参与真实 propagation/backtrack 路径；
  不运行第二次反事实求解，也不解析 debug 日志伪造证明。
- 求解器原生支持同版本不同内容候选、owner-bound Jar-in-Jar occurrence 与完整 Pareto
  极大方案枚举。
- 唯一方案自动选择；多个不可支配方案在 add/install/sync/upgrade 等公共路径中要求
  用户选择，并高亮方案间不同动作。
- upgrade 只要求至少一个包真正升级，允许为实现整体可行方案而降级其它包；所有替换与
  删除都在写盘前以逻辑包为单位展示并确认。

### 实例、平台与事务

- `orbit init` 支持标准共享游戏目录、隔离 `versions/<实例>`、HMCL、
  Prism/MultiMC、CurseForge profile 和 GDLauncher 常见布局。
- init/sync 是唯一允许探测 Minecraft、Loader 与 runtime JAR 的边界；其它命令只消费
  manifest 中的精确路径和 SHA-256，不猜测、不兜底、不静默刷新。
- sync 保持离线并重新扫描本地平台与 mods；install 负责联网恢复缺失依赖。
- 事务计划统一处理安装、升级、降级、同版本内容替换和未选包删除，并在确认后一次落盘。

### 缓存、配置与输出

- content-addressed JAR cache 使用持久化标准 LRU；每次命令结束后按
  `cache.capacity-mib` 清理，命中内容不会重复下载。
- `orbit config path/list/get/set/unset` 提供强类型全局配置管理，原子保留 TOML 注释，
  API Key 在 text/JSON 输出中始终脱敏。
- 长事务分别报告 project 发现、候选下载/解析、动态求解工作量和物化进度。
- 所有主要命令支持自适应文本表格与稳定 JSON 信封；NDJSON 进度与结构化错误走
  stderr，内容哈希、物理 JAR 文件名和 provider 密钥不会进入公开结果。

### 字节码兼容风险审计

- `orbit audit` 复用 Loader 实际选择的顶层与嵌套 JAR。
- Fabric/Quilt 按各自 Loader 规则选择 official identity 或使用现有 Tiny mapping 对齐
  运行时 namespace，支持 Minecraft 26.1+ 的无混淆运行时；
  Forge/NeoForge 验证 Loader runtime game。
- 分析已激活的 Mixin config/refmap、Plugin 决策和 ModLauncher transformer，并把
  readiness、coverage、单体风险、交互风险和证据分层输出。

## 已知边界

- 0.1.0 是首个公开 schema；不提供早期开发版 manifest/lockfile 的兼容读取层。
- CurseForge 功能必须配置 `auth.curseforge-api-key` 或
  `ORBIT_CURSEFORGE_API_KEY`。
- deb 当前只提供 `amd64`；Windows 当前只提供 x64 MSI。
- MSI 尚未签名。
- 字节码审计只能报告有证据的潜在兼容风险，不能证明反射、native code、配置、资源或
  游戏业务行为一定兼容。
- `network.proxy`、统一 retry、语言、颜色和下载并发等部分全局配置已经进入 schema，
  但尚未全部接入每个运行路径。

完整命令与设计契约见仓库 `README.md` 和 `docs/`。
