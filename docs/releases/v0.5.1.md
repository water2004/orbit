# Orbit 0.5.1

Orbit 0.5.1 is a Windows launcher and GUI reliability update.

- Orbit Launcher now resolves Mojang logging configurations from the official shared `assets/log_configs` layout and expands the existing `${assets_root}` runtime placeholder. It no longer invents a launcher-specific placeholder or places logging configuration beside the shared Minecraft directory.
- The GUI now loads package ownership when **Manage → Files & data** is opened and commits results only to the matching package request. Superseded results cannot overwrite the current package.
- Package ownership failures are shown in the management panel with a retry action instead of being indistinguishable from an empty ownership record.
- The ownership panel includes an explicit refresh action.

## Packages

- Windows: `orbit-0.5.1-x86_64.msi` installs Orbit and its Runtime Agent, Orbit Launcher, and Orbit GUI using the selected setup profile.
- Linux release automation continues to produce the three independently installable Debian packages when `v0.5.1` is published.

The Windows MSI is currently unsigned, so Windows may display an unknown-publisher warning.

## 简体中文

Orbit 0.5.1 是针对 Windows 启动器和 GUI 的可靠性更新。

- Orbit Launcher 现在按照 Mojang 官方布局从共享的 `assets/log_configs` 目录读取日志配置，并使用既有的 `${assets_root}` 运行时占位符；不再创造启动器私有占位符，也不会把日志配置错误地放在共享 Minecraft 目录旁。
- GUI 在打开**管理 → 文件与数据**时读取包所有权，并按包与请求序号提交结果，迟到的旧请求不会覆盖当前包。
- 包所有权读取失败会直接显示在管理面板中并提供重试，不再与“确实没有归属数据”混淆。
- 文件所有权面板新增显式刷新操作。

Windows MSI 当前没有代码签名，系统可能显示“未知发布者”提示。
