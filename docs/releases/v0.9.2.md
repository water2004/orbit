# Orbit 0.9.2

- Mod sources can now be changed from the instance's mod management page, with automatic saving.
- Fixed `sync` using CurseForge when it was not enabled for the instance.
- Fixed `sync` failing on CurseForge files without a download URL.

Existing instances and configuration remain compatible. Windows: unsigned MSI (requires WebView2). Linux: three separate DEBs.

## 简体中文

- 实例的模组管理页新增“模组来源”，修改后自动保存。
- 修复实例未启用 CurseForge 时，`sync` 仍使用该来源的问题。
- 修复 CurseForge 文件没有下载地址时导致 `sync` 失败的问题。

现有实例与配置保持兼容。Windows 提供未签名 MSI（需要 WebView2）；Linux 提供三个独立 DEB。
