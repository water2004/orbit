# Orbit Launcher 0.1.0

Orbit Launcher 是与 Orbit 模组包管理器完全隔离的 Minecraft Java Edition 运行时工具。

首个版本包括：

- 全局实例注册、稳定 UUID 与当前目录实例上下文；
- 一条命令安装 Vanilla、Fabric、Quilt、Forge、NeoForge 客户端或独立服务端；
- Mojang 官方元数据、受管 Java、libraries、assets、natives 和 Loader installer 的哈希校验；
- 安装服务端前完整展示当前 Minecraft EULA，并要求对所展示正文作显式确认；
- Microsoft device flow、Offline 与标准 External Yggdrasil 账户；
- Windows 当前用户 DPAPI 与 Linux Secret Service 中的可续期 session 持久化，不使用明文回退；
- 经校验的 Authlib Injector 客户端/服务端接入；
- 客户端启动、服务端前台监督，以及带本机 IPC、优雅停服和异常重启的后台 supervisor；
- text、JSON 最终结果和 NDJSON 进度协议。

不包括 mod 管理、LittleSkin 专属 OAuth、联机大厅、系统服务、开机启动或退出登录后保活。

发布物：

- `orbit-launcher-0.1.0-x86_64.msi`；
- `orbit-launcher_0.1.0-1_amd64.deb`；
- `SHA256SUMS`。

Windows MSI 当前未签名。Linux 客户端账户需要当前登录会话可用且已解锁的 Freedesktop
Secret Service；没有它时会明确报错，不会把 token 写成明文。纯服务端运行不需要账户凭据。
